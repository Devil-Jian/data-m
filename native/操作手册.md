# 论文原始数据管理平台 · 操作手册（WinUI 3 原生版）

适用：Windows 10/11 x64，C# + .NET 10 + WinUI 3 测试版。

## 一、开始

1. 关闭旧版程序。**先备份整个 `D:\PaperArchiveData` 文件夹。**
2. 启动 WinUI 原生程序。默认使用 `D:\PaperArchiveData`。
3. 如果电脑没有 D 盘，或者数据仓库尚未初始化，第一次归档时选择一个单独的仓库目录。
4. 原始文件只存在电脑本地，不上传网络。

建议先用模拟论文测试，真实科研数据不要只保留软件仓库这一份。

## 二、准备文件夹

```text
论文标题/
├── 论文正文.pdf                 # 或 docx
├── Figure/
│   ├── 组合图/
│   │   └── Figure1-完整组图.png
│   ├── 子图/
│   │   └── 1-A-1-荧光图.tif
│   └── 统计原始图/
│       └── 1-A-2-重复实验.tif
├── Table/
│   ├── 1-A-ROS统计.xlsx
│   └── T1-样本信息.xlsx
└── Others/
    └── 补充说明.pdf
```

**命名规则**：`组图编号-Panel字母-图片序号-描述`，如 `1-A-1-Control.tif`。大小写均可；兼容 `2-a9.tif`。组合图名称用 `Figure1.png`，独立论文 Table 用 `T1-名称.xlsx`。

## 三、归档前整理

1. 顶部选择 **论文归档**，点击 **打开文件夹**。
2. 左栏按 Figure、Table、Others 等目录切换；中间显示文件，右侧查看选中文件的信息。
3. 多选文件，然后点击 **批量分类** 修改数据角色；或者点击 **批量编号** 设置 Figure、Panel 与起始序号。
4. 批量编号时，新名称只在归档数据库中生效，源目录里的文件不会被重命名。
5. 整理完成后点击 **完成归档**，确认归档；程序会将原始文件按 SHA-256 保存，并自动生成论文、Figure、Panel 和引用关系。

**注意：** 当前原生测试版提供批量分类、批量编号和上下文菜单；高级拖拽移动、批量重命名预览、可视化撤销/重做等交互还需后续完善。鼠标右键可打开常用操作菜单。

## 四、归档后浏览

1. 点击顶部 **论文资源库**。
2. 左侧选择论文。
3. 中间查看 Figure/Panel 对应资源，右侧查看文件信息与支持的图片缩略图。
4. 选中文件并用鼠标右键选择 **打开原始文件**，可在资源管理器中定位。

**预览限制**：PNG/JPEG/WebP 适合内嵌预览；TIFF、XLSX、CZI、ND2 等可归档，内容深度预览尚未完成。当前原生界面尚未实现 PDF/DOCX 正文内部的图表点击跳转，后续会接入论文阅读器。

## 五、升级与安全

- 新版读取与保留原先 SQLite v1/v2/v3 资源库的数据结构，不重新分配旧 Data ID。
- 第一次升级旧数据库前，软件会额外生成 `database/archive-pre-winui-*.db` 备份，但**仍需要手动备份整个数据仓库**。
- 原始文件按 SHA-256 内容地址保存，不应在 `blobs` 目录手动移动或重命名文件。
- 同一个文件名并不能保证数据相同；软件通过内容哈希判断文件内容。
- 暂未实现跨电脑 `.rdpack` 汇总、历史修订回滚和全格式科研文件预览。

## 六、开发

工程目录：

- `native/PaperArchive.Core`：扫描、归档、SQLite 兼容、SHA-256。
- `native/PaperArchive.Native`：WinUI 3 原生界面。
- `native/PaperArchive.Core.SmokeTests`：无需外部测试框架的兼容性验收程序。
- `src-tauri/migrations`：沿用的原始 SQLite v1～v3 迁移脚本。

Visual Studio（含 WinUI 开发组件）或 Windows 环境下：

```powershell
dotnet build native/PaperArchive.Core/PaperArchive.Core.csproj -c Release
dotnet run --project native/PaperArchive.Core.SmokeTests/PaperArchive.Core.SmokeTests.csproj -c Release
dotnet build native/PaperArchive.Native/PaperArchive.Native.csproj -c Release -p:Platform=x64
```

软件仍处于 Windows 原生架构迁移测试阶段，后续正式版本应在真实 Windows 10/11 电脑完成端到端验收后再替换旧版。

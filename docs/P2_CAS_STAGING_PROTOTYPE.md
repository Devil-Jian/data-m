# P2 · CAS 流式复制原型（Issue #6 / #15）

## 实现（仅 Rust 测试模块）

`apps/desktop/src-tauri/src/cas.rs` 提供 `copy_file_to_cas(source, root)`：对只读源文件按 1 MiB 块读取，同时计算 SHA-256，写入 CAS 根目录内的 `staging/` 临时文件，完成同步后采用 no-clobber 原子持久化到 `objects/aa/bb/<sha256>`。

- 源必须是绝对路径指向的普通文件；拒绝最终路径为符号链接的源、相对路径、目录与 CAS 根目录内的源。
- staging 与对象目录位于同一 CAS 根目录；源码中没有删除、移动或写入源路径的操作。
- 源文件在流式读取前后检查大小、修改时间，检测到变化时拒绝登记该次复制。
- 目标对象已存在时重新计算实际 SHA-256 和大小；只允许内容一致的去重，绝不覆盖目标文件。
- 异常返回前，由临时文件封装负责清理尚未持久化的 staging 文件。
- 测试使用临时目录和人工生成文件，不读取真实科研原始数据。

## 明确安全边界

**这是原型，不是可用于真实科研数据的归档 API。**

尚缺：
1. 不可变 CAS 目录的权限、父路径/链接竞争防护以及源文件并发变动时的可靠快照/锁定。
2. 跨平台真实断电与 fsync 目录持久化保证（Windows 文件系统及共享盘需独立评估）。
3. staging 恢复与崩溃后孤立临时文件清理。
4. 与 SQLite 的注册事务协调及后台 reconcile；不允许出现孤立 AssetVersion/Blob。
5. 用户授权、文件路径策略、导入队列、取消/进度、磁盘配额和空间不足故障注入。
6. 审计、备份恢复、损坏 CAS 回滚及真实 Windows GUI 验收。

本模块**没有注册 Tauri IPC 命令**，应用界面无法调用；正式导入保持关闭。任何实际文件操作都必须先完成上述门禁，不能把此 PR 合并后直接对科研文件开放。

## 测试

```powershell
cd apps/desktop/src-tauri
cargo test
cargo fmt --all -- --check
cargo check
```

当前测试：源文件 SHA/大小/时间不变、重复导入内容去重、目录/不存在的路径拒绝、内部 CAS 文件拒绝二次导入、已损坏 CAS 目标绝不覆盖；Unix 下额外测试源符号链接拒绝。

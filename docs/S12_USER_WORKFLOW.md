# Data-M S12 统一工作区操作说明（测试候选）

本说明适用于 S12 开发分支 `feat/s12-unified-workspace`。所有数据操作依赖真正的 Tauri/Rust IPC 与受控 SQLite/CAS 仓库。浏览器 `http://127.0.0.1:5176` 若未注入**显式测试 Mock**，不具备原生存储；没有真实写入就不会显示“已保存成功”。

**数据安全：** 目前只可使用可抛弃测试数据。勿以唯一或珍贵科研数据验收；未进行 Windows 11 GUI 手工签收。未签名 EXE、NSIS 安装器为开发候选而非正式发布。

## 1. 唯一入口和目录定位

打开应用直接进入**项目管理**，不再切换“演示工作区”。新建 Project（科研项目），其下新建 Theme（研究主题），在 Theme 下新建 Assay（实验）；真实项目树、面包屑和后退/前进都基于数据库返回的 ID。最后选择实验进入**分组与样本**。可在顶部和模块内使用 `Alt+←` / `Alt+→` 返回最近的项目位置；重启时仅恢复后端确认仍存在的项目节点。

在 Assay 创建 Group 分组，再建立 Replicate 生物学重复。实验总 `n` 和统计分析单独纳入的 `n` 都来自原生业务接口，新增文件关联不会新增生物学重复。

## 2. 四阶段范围

| 阶段 | 合法目标 | 说明 |
| --- | --- | --- |
| Raw | 实验 + 分组 + 单个 Replicate | 原始文件 |
| Processed | 实验 + 分组 + 单个 Replicate | 处理版本 |
| Statistics | 整个 Assay | 统计结果文件，不能附带 Replicate |
| Display | 整个 Assay | 论文展示候选文件，不能附带 Replicate |

Raw/Processed 未选中具体样本时，文件操作不可写。Statistics/Display 不使用上一次的样本 ID。切换阶段或样本后，旧文件可写选区失效。

## 3. 正式 Explorer 操作

浏览器每次从 `list_assets` 查询最多 50 个真实关联，以 `AssetLinkId` 区分可执行操作对象，以 `AssetVersionId` 区分固定版本。使用“列表 / 网格 / 表格”选择展示方式，不会变更数据来源。支持名称搜索、排序、上下页、详情与有真实证据时的溯源。**没有真实缩略图时仅显示名称/元数据**，不会显示演示图片。

- 单击文件名称选中；`Ctrl+单击` 增减选区；`Shift+单击` 按当前页锚点连续选择；`Ctrl+A` 仅选择当前页。网格中从空白处拖拽矩形可框选当前可见文件，`Ctrl` 可叠加；不会跨页加载或勾选额外的 10k 文件。
- 在选中的文件上右键，或将焦点放到文件名后按 `Shift+F10` / 菜单键，打开真实文件菜单。上下方向键切换菜单项，Escape 关闭并将焦点返回文件。点击菜单外关闭。
- `Ctrl+C` 复制关联，`Ctrl+X` 剪切关联；到达合法目标的阶段视图后 `Ctrl+V` 粘贴。实际复制/移动由 `asset_transfer` 校验源范围、原版本 ID、目标、幂等请求及冲突。**仅在提交并收到受校验响应后**报告成功，随即重新查询。剪切/复制不会增加生物学重复，不覆盖原始 CAS。
- 已入库关联的内部拖拽需显式 `Ctrl`（复制）或 `Shift`（移动）才能提交；没有修饰键不会默认移动。拒绝不合法样本/实验阶段目标。
- `F2` 仅对选中的一个真实关联打开重命名确认；`Delete` 打开逻辑回收确认。完成后刷新真实列表。回收区可以按原合法范围恢复，名字冲突、固定版本/论文引用保护由现有 S6 后端审查；**不会物理删除磁盘文件或 CAS Blob**。

操作期间请勿跨项目切换；事务失败、来源改变、目标失效或查询未确认时不会伪造成功消息。

## 4. Windows 外部文件和安全导入

将系统外文件拖入普通窗口只得到**只读检查预览**，不会导入。进入具体 Assay 的**分组与样本**，选择合法阶段、样本或实验级目标，打开**安全导入（测试库）**；再把可丢弃测试源拖入应用窗口。S3 仅 `prepare` 创建待确认任务；确认固定目标、文件条目后按“确认导入”才执行 `start`。

支持取消、逐项错误和只重试未完成文件；完成量基于后端 `ImportJob.completedCount`，不是自增 UI 数字。源文件路径不会放入任务状态栏。任务未结束时不能切换样本或模块。**文件名称不会自动推断实验/阶段**。

## 5. 统一任务状态栏

有已验证任务状态时，右下角出现“任务状态”。展开可查看安全导入、仓库完整性/备份/隔离恢复、Figure 无损导出的当前进度或错误。不需要时收起；此栏只是原生业务状态的只读摘要。

取消和重试仍回到对应原生模块操作。特别是**已请求取消**不同于“已经取消”，等待真正的完成/失败结果后才会更新。本栏不冒充任务数据库，不持久保存历史；重新打开应用需在原功能页面查询。

## 6. 统计分析、论文与数据安全

统计模块单独选择纳入的 Replicate 与版本；冻结后的分析只读，后续改动须使用修订。论文模块中的 Paper / Figure / Panel 按 `AssetVersionId` 锁定引用，面板内容和来源不能由显示名称推断。切换论文所在项目时，正式项目导航同步到该项目。

Figure 导出先预览精确范围，再由原生接口选择目标、校验固定 CAS 版本与 SHA-256 Manifest；支持取消请求，不以“取消已请求”当作完成。仓库安全模块只允许只读核验、设备内封存快照与新目录隔离恢复。**设备内备份不是异地备份**，恢复不会覆盖运行中的仓库。

## 7. 可追踪的验收证据

开发结果与 CI 证据记录于 [S12 执行报告](S12_MIGRATION_EXECUTION_REPORT.md)、[机器验收矩阵](S12_MACHINE_ACCEPTANCE_MATRIX.md)。Playwright 注入 Mock 仅证明前端行为，不证明 Windows 原生 GUI 或珍贵数据安全；手工检查仍保持 `manual_pending`。

本阶段不修改 Schema v3，不改 CAS 原字节，也不自动合并 `main`。

# PaperArchive V1.4 手工验收脚本（Windows 10/11）

版本：PRD V1.4 / 分支 `feat/wpf-desktop`

## 前置条件

请使用 `dotnet run --project native/PaperArchive.Wpf/PaperArchive.Wpf.csproj` 启动 Debug。
首次运行时默认测试仓库是 `D:\PaperArchiveDevData`（若无 D 盘，改用 LocalAppData）。
不要连接正式论文仓库进行此轮测试。

导入此前生成的“模拟论文项目”测试数据，准备包含
`01_ROS检测`、`02_WesternBlot`、`03_细胞活力` 三个结果单元的实验项目。

## 操作清单

| 编号 | 操作 | 预期 |
|---|---|---|
| 01 | 点击论文项目 | 列出它所有实验项目下的资源，状态栏总数正确 |
| 02 | 点击实验项目 | 显示该项目所有结果单元的文件 |
| 03 | 点击结果单元 | 只显示该单元文件；“所属实验结果”列折叠 |
| 04 | 点击 show_data | 在当前选中层级内仅显示 SHOW 文件 |
| 05 | 多选后拖动到结果单元 | 默认逻辑移动，SHA-256、Asset ID 保持 |
| 06 | Ctrl + 拖动到结果单元 | 创建新的 Asset ID，同内容共享 blob |
| 07 | 拖动到实验项目 | 放进该项目的“待整理数据” |
| 08 | 拖动到论文项目 | 要求选择目标实验项目 |
| 09 | 拖动到空白处 | 不产生移动、复制或数据库修改 |
| 10 | 右键项目树空白 | 只含三种“新建”，不适用项置灰 |
| 11 | 右键项目节点 | 出现与对象对应的菜单 |
| 12 | 点击新建 / 导入 / 导出菜单 | 内容与 V1.4 PRD 一致 |
| 13 | 使用剪切、复制、粘贴 | 与右键入口作用一致 |
| 14 | 通过功能栏和表头排序 | 一致的排序状态 |
| 15 | 调整浏览区域高度 | 浏览位置保持底部，树独立滚动 |
| 16 | 隐藏右侧详情栏 | 主列表扩展；再次点击恢复 |
| 17 | 双击任一列的表头 10 次 | 不打开文件 |
| 18 | 双击空白区域 | 不打开文件 |
| 19 | 双击不同文件行 | 打开实际双击的文件，而不是第一张 |
| 20 | 核对模拟项目文件校验清单 | 原始文件哈希不变 |

### 说明

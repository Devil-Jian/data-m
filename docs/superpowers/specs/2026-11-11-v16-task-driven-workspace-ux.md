# V1.6 任务驱动论文工作台与索引归档体验

状态：V1.6-A 已开始实现（`feat/v16-task-driven-workspace`）；V1.6-B/C 待实施。
基线：`feat/wpf-desktop`；沿用现有 WPF 风格，绝不引入像素化界面。

## 设计目标

一次导入、自动建立客观索引；用户使用 SHOW 时产生引用；仅对真实科研判断与异常进行核对；论文就绪后用一次确认生成不可变归档。所有交互围绕论文对象而非数据库表展开，不强迫按固定顺序操作。

## V1.6-A：任务概览、主文稿、归档（本分支第一批代码）

- 单击论文根节点进入“任务概览”；单击实验、组图、论文全文仍进入原文件管理界面。
- 项目进度：文稿、完整 Figure、已确认论文关系、实验素材。
- 任务来自实时模型查询，不保存可被手动误勾选的完成标志。
- P0 阻断：未导入全文、多文稿未选择主稿、未关联任何 Figure、论文引用未锁定成图版本。
- P1 待核对：成图来源快照或明确 PROCESS/RAW 加工关系不完整。仅警示，不冒充已确认。
- 任务操作跳转对应数据对象，不经过层层导航；变更后重新进入项目根节点即可刷新。
- 文稿只有一份时自动作为主稿；多份时选择一次，存储稳定文档 ID，后续归档默认使用。
- 归档仍在提交前做 Blob SHA-256 全量校验，页面摘要不是最终完整性保证。
- 无阻断且无待核对项：一次归档确认；待核对项必须明确同意以“未核实”状态保存。
- 未变化的归档内容使用旧 Revision；变更后生成新 Revision；既有 Manifest 永不改写。

## V1.6-B：自动整理、直接引用与增量索引（下一批）

- 导入标准目录时自动识别 RAW/PROCESS/SHOW 和数据组；混合目录默认保留原路径，集中处理不确定分类。
- 拖 SHOW 到已有 Panel 自动建立引用；拖入 Figure 空白处新建 Panel；多选可批量建 Panel。
- 保存用户拖拽确定的关联，不把同组候选自动升级为科研处理事实。
- 统一来源与反向引用索引：从 Paper→Figure→Panel→SHOW→PROCESS→RAW 查询，也能从素材反查所有论文与归档。
- 文件移动、重命名、Panel 替换、工作版本切换按稳定 ID 增量维护索引；错误操作支持撤销。

## V1.6-C：高效 Figure 与归档资源库浏览（后续）

- Figure 主页面展示成图预览、版本历史、Panel 缩略图，操作就地进行。
- 论文集中核对推荐版本；批量确认，但必须保留对实际采用版本的显式判断。
- 资源库内联选择 Revision，直接展开不可变溯源，不依赖额外多级对话框。
- 支持论文/实验/文件/数据组/哈希全局检索；从任意 SHOW 查看上游与使用位置。

## UI 统一规则

1. 项目根节点=任务概览；子节点=文件浏览；切换时保持树结构与逻辑对象身份。
2. 顶部只显示当前上下文相关的常用操作；高级命令藏于“更多”或右键。
3. 单击选中并预览，双击/Enter 打开，F2 重命名，Delete 仅删除逻辑引用或经过明确确认的对象。
4. 已完成的普通操作不再弹出成功提示；错误、风险操作、归档发布才要求确认。
5. 对科研来源的“候选”和“已确认”必须显著区别；不虚构 RAW/PROCESS/SHOW 加工关系。
6. 归档依赖内容哈希与不可变版本快照，不重复复制文件，不删除工作台原件。

## 第一阶段验收

- 多文稿论文进入任务中心会提示选择主稿，选择一次后重开仍有效。
- 无全文、无论文 Figure 关联、待指定成图版本时，各自生成相应任务。
- 已确认 Figure/来源由数据状态自动决定；无需点击“任务完成”。
- 从任务进入正确论文/Figure/来源节点，不误选其它对象。
- 单文稿归档无需文稿选择弹窗；校验通过仅作一次最终确认。
- 带未核实来源的归档必须显式同意；损坏 Blob 或缺失引用禁止发布。
- 相同 Manifest 重复提交仍返回原 Revision；内容更改生成新版本且旧版本不变。
- Core、Workspace SmokeTests、WPF Windows 编译及便携版发布通过。

## 兼容与风险

保留现有 workspace.db、archive.db、SHA-256 blobs 和 Figure/Panel 稳定 ID，仅追加可向后兼容的偏好表及视图层。工作台任务不是独立的事实来源，而是当前数据库关系的投影。归档历史记录是只读快照，不被后续编辑覆盖。V1.6-A 的任务摘要为了保持界面响应，不在每次点击论文根节点时重新读取全部图片字节；最终归档的 SHA-256 预检仍是必须步骤。

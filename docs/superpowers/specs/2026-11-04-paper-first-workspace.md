# 以论文为中心的工作台（需求修正 / 迭代 0.2）

## 核心交互

窗口采用三栏布局：
- 左：论文条目列表（类似 EndNote），搜索、创建、选择论文；旧版已导入但尚未关联的数据保留。
- 中：论文 PDF / DOCX 预览、图表区域标注、当前论文的 Figure / Panel / Table 结构。
- 右：论文资源库，按 Figure / Panel / Table 分组展示关联原始数据；点击图片区域或文章表格定位并高亮其资源目录；可以查看数据文件大小、SHA-256、导入时间、引用位置，以及在资源管理器打开文件。

## 图表点击规则

文章 PDF 和 DOCX 不天然拥有对原始科研文件的引用关系，因此首次需要把原文中的图形或表格位置与 Figure/Panel/Table 条目建立映射：
- PDF：选择 Figure / Panel / Table，启动“在文章中框选绑定”，拖框选出图表在当前 PDF 页面的区域，记录页码和归一化矩形坐标；此后点击区域可跳转右侧资源组。
- DOCX：选择条目、启动绑定，然后点击正文中对应图片或表格，记录元素类型和出现序号；点击元素可打开资源组。
- 右侧可以直接点击条目并关联原先导入的 Data ID，也可以在条目下导入新的文件。

点击后需同时选中对应的 Figure/Panel/Table、滚动右侧资源区域，并展示当前数据的元信息。一个条目允许多文件，一个数据可用于多篇论文。

## 论文预览

- PDF：PDF.js，按页渲染，支持图表框选热点；初版限制一次仅渲染一页并设置文件大小保护。
- DOCX：docx-preview，在软件内只读 HTML 预览，图片/表格点击绑定。
- 旧 DOC 暂不支持内嵌预览，提示转换 PDF 或 DOCX。
- 在 Paper 表中记录文章文件的 Blob SHA-256、原文件名和扩展名，原文与原始数据共享不变的内容寻址仓库。

## 数据结构与迁移

- 从现有 SQLite schema v1 原地迁移到 v2，不删除原有 Data Record 或 Blob。
- papers 新增 manuscript_* 字段；paper_items 新增 anchor_* 字段。
- data_references 仍是多对多中间表，保持 UUIDv7、SHA-256、不可变 Blob。
- 原始文件不会因为从旧界面切换到新论文工作台而丢失；尚未关联的文件可从左侧/右侧资源选择器关联。

## 验收场景

1. 创建论文 A 和 B，重新启动仍保留。
2. 给 A 导入 PDF 或 DOCX，在中栏阅读；文件元数据可查。
3. 创建 Figure 1、Panel A、Table 1。
4. 将已有 Data ID 关联到 Panel A，并可在右栏查看详细数据和文件目录。
5. PDF 框选图片区域（或 DOCX 点击图片）绑定 Panel A；再次点击文章图片，右栏自动滚动定位到 Panel A。
6. 一个 Data ID 在不同 Panel/论文下引用，能显示全部引用位置。
7. 从 v1 更新后，原有归档数据不丢失，仍可关联到新论文。
8. 大型不支持预览的论文文件得到明确提示，原文件不受影响。

# Data-M 产品需求说明书（PRD v0.1）

> 状态：开发基线草案；产品与 Windows 真机验收尚未最终签署。
> 路线：React + shadcn/ui + Tauri 2 + Rust + SQLite/CAS；以原有 Gemini 工作台布局为视觉/业务基础。
> 范围：Windows 11、单机、离线优先、实验科研素材与论文图表数据全流程管理。

## 1. 用户问题与产品目标

科研图片、统计源文件和论文组图分散于大量磁盘文件夹，归档容易丢失实验上下文，论文 Figure/Panel 难以回到原始样本；普通文件管理器无法同时管理生物学重复、统计纳入与论文版本。

Data-M 的目标：
1. 像 Windows Explorer 一样直接操作文件（矩形框选、Ctrl/Shift 多选、拖拽移动/复制）。
2. 以项目、主题、实验、分组、样本构建完整的科研实验语义。
3. 用 Raw/Processed/Statistics/Display 四阶段保存与组织真实数据资产。
4. 按 Paper → Figure → Panel 组织论文；支持双向追溯来源。
5. 不得让文件的移动、复制或重命名导致原始数据损坏、统计重复计数或论文断链。

## 2. 用户和运行环境

- 主要用户：个人科研人员、论文第一作者、实验组成员（第一版默认单机单用户）。
- 系统：Windows 11，支持 NTFS 以及常规本地/外置存储目录。
- 工作模式：独立 EXE；无需主动打开浏览器或运行 Node 开发服务；无网可使用。
- 体量：从少量图像到大量 TIFF/显微图与统计表，必须允许大文件流式操作和批量文件。
- 不实现：第一版云同步、多用户权限协作、实时多人协同编辑。

## 3. 信息架构

```
Project
  └─ Theme
      └─ Assay
          ├─ Group
          │   └─ Replicate (生物学重复)
          │       ├─ Raw assets
          │       └─ Processed assets
          ├─ Statistical Analysis (输入样本集合/统计文件)
          └─ Display assets
Paper
  └─ Figure
      └─ Panel
          ├─ Display/Source asset-version links
          ├─ Statistical analysis links
          └─ Representative source references
```

重要：`Replicate` 是实验样本实体，`DataAsset` 是文件资产实体，复制文件不能复制 `Replicate`。一个文件可关联多个实验上下文或论文 Panel，必须通过稳定版本 ID 追溯。

## 4. 界面和交互需求

### 4.1 整体布局

保留现有 Gemini 演示的顶部深色导航、左侧项目/实验树、主工作区、状态栏、实验整理/论文管理两大模块。主要工作区支持全阶段全景和单阶段浏览，提供网格、列表、详细表格视图。

### 4.2 Windows Explorer 交互

| ID | 用户动作 | 预期效果 | 优先级 |
| --- | --- | --- | --- |
| EX-01 | 单击资产 | 当前单选、显示聚焦 | P0 |
| EX-02 | Ctrl + 单击 | 增加/取消非连续选择 | P0 |
| EX-03 | Shift + 单击 | 从锚点连续选择（双向） | P0 |
| EX-04 | Ctrl + A | 选择当前数据作用域内全部可见资产 | P0 |
| EX-05 | 空白处左键框选 | 半透明选区、任意方向选取资产 | P0 |
| EX-06 | Ctrl + 框选 | 在起始选择集合上追加命中的资产 | P0 |
| EX-07 | 多选资产拖到合法逻辑目录 | 显示数量、目标高亮、提交统一操作请求 | P0 |
| EX-08 | Ctrl + 拖拽 | 强制复制逻辑资产 | P0 |
| EX-09 | Shift + 拖拽 | 强制移动逻辑资产 | P0 |
| EX-10 | Esc / 非法目标 | 取消操作、不得产生文件更改 | P0 |
| EX-11 | Ctrl+C/X/V | 复制/剪切/粘贴所选资产到指定目标 | P1 |
| EX-12 | Delete / F2 | 回收站逻辑删除 / 重命名 | P1 |
| EX-13 | 从 Windows Explorer 拖入 | 安全复制导入；原位置不删除 | P0 |
| EX-14 | 拖出到 Windows Explorer | 生成真实文件到外部目标（OLE/COM） | 后续独立任务 |

不同视图共用同一选择模型；用户在输入框输入文字时，文件快捷键不能截获输入；拖拽时不应无故取消已有多选。

### 4.3 实验与统计业务

- 项目/主题/实验/分组/生物学重复的 CRUD 与导航。
- Raw/Processed/Statistics/Display 按实际文件资产建立角色关系，而非简单重命名文件。
- 允许用户指定某次统计分析的样本纳入集合、对应统计结果版本；不改变生物学重复记录。
- 支持多个统计分析版本、代表图源版本，旧统计和组图引用须稳定。
- 在视图中展示纳入统计标记与论文引用来源。

### 4.4 论文与溯源

- Paper / Figure / Panel 创建、排序、重命名、删除（有引用保护）。
- 一个 Panel 可以引用多个展示源文件版本和多份统计源。
- Panel → 展示/统计 → 处理/原始 → Replicate 正向追溯。
- AssetVersion → 所有相关 Figure/Panel 反向追溯。
- 将图像无损导出至目标文件夹，并同时导出可审计的清单（Asset ID、SHA-256、来源、版本、Panel）。

## 5. 文件安全与一致性（非功能需求）

- 原始科研文件采用复制导入，用户源目录不能被静默移动或删除。
- 入库使用 staging、校验、原子完成和故障恢复机制；SQLite 事务不等于文件系统事务。
- 文件内容以 SHA-256 存储在 CAS；逻辑移动/复制不产生新的生物学重复。
- 对已被论文或冻结统计引用的版本保留稳定引用；禁止静默物理删除。
- 提供软删除、错误恢复、审计日志、SQLite 迁移、数据备份/恢复。
- 文件名冲突、容量不足、文件锁/取消/异常退出必须明确反馈并可恢复。

## 6. 性能与易用性

- 长时间操作和大文件哈希应交给后台任务，UI 进程保持响应。
- 10k+ 资产可浏览、过滤、滚动；虚拟列表下范围选择依然正确。
- 图片缩略图可缓存；不在前端一次性读取整个 TIFF/显微文件。
- 错误信息必须解释原因和可执行修复建议，不能只返回未处理异常。

## 7. 分阶段交付

| 阶段 | 交付物 | 退出条件 |
| --- | --- | --- |
| P1 客户端/交互 | Tauri 2 Windows 窗口、统一选择/拖放、快捷键 | Windows E2E 实测达标，外部拖入不损坏源文件 |
| P2 资产存储 | SQLite、CAS、文件任务、版本和备份 | 故障注入、恢复和一致性校验通过 |
| P3 科研业务 | 实验/论文/组图/统计及双向溯源 | 全业务 E2E 与回溯/无损导出通过 |
| P4 发布 | 性能、安装/升级、回归测试、Release | 干净 Windows 11 安装/备份恢复与发布门禁通过 |

## 8. 不在当前版本承诺的功能

- 云端同步与多人账号。
- 完整 Windows Shell 扩展与系统文件管理器全部内部特性。
- 所有医学/显微格式的深度图像解析。
- AI 自动图像分类、统计自动化、计算生物学分析引擎。

这些功能可以单独形成后续 Feature Issue，不能默认为已经实现。

## 9. 产品验收情景

1. 用 Windows Explorer 将一批图像拖入某个实验单元后，源文件不变，Data-M 列表可见新 Asset。
2. 在网格/列表中使用 Ctrl/Shift/框选选中 10 个真实 Asset，拖入另一个 Group，视图和数据库记录一致。
3. 对 6 个 Replicate 复制一份 Raw 文件，生物学重复数依然是 6。
4. 创建统计分析并明确仅纳入 5 个 Replicate；导出结果清单可追溯这 5 个样本。
5. 将处理图和统计结果关联 Panel，重命名/逻辑移动图像后 Panel 引用仍可用。
6. 关闭应用、断开网络、重新打开，数据关系保持不变；备份可恢复。
7. 在外部复制/导入中途模拟失败，检查源文件与已入库数据不受损坏。

> 每项情景都需用实际 Windows 软件验证。浏览器模拟数据不构成正式验收。

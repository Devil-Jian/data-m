# Data-M 测试与验收计划 v0.1

## 测试分层

| 层 | 技术 | 测试内容 |
| --- | --- | --- |
| 规则单元测试 | Vitest / Rust unit tests | 多选、框选、拖拽规则、领域不变量 |
| 组件测试 | React Testing Library（待加入） | 选择状态、操作取消、错误提示 |
| IPC/集成测试 | Rust + SQLite temp DB | 资源移动、CAS 引用、版本关联与事务 |
| Windows E2E | WebView2 + 驱动（待选型） | 真实鼠标/键盘拖放、窗口操作 |

| 发布验证 | Windows 11 VM/实机 | 安装、升级、迁移、备份恢复 |

## 验收矩阵

### P1
- [ ] Ctrl 单选/Shift 连选/反向框选一致；
- [ ] 已选集合整体拖拽且不会意外丢失选择；
- [ ] 当前不允许放置的位置不得提交操作；
- [ ] 输入框内 Ctrl+A/C/X/V 不触发文件级操作；
- [ ] 真实 Windows 11 WebView2 可打开独立窗口；
- [ ] 外部 Explorer 拖入仅在用户确认后才修改仓库。

### P2
- [ ] 所有 SHA-256 对照入库源字节一致；
- [ ] 中断/取消/磁盘满时不留损坏的已确认版本；
- [ ] 数据库迁移具有版本和回退说明；
- [ ] 备份恢复可重新关联 Blob 与 AssetVersion；
- [ ] 复制一个文件不增生物学重复。

### P3
- [ ] Panel 引用具体 AssetVersion，不因路径改变丢失；
- [ ] 统计纳入集合独立于 Asset 数量；
- [ ] 正反双向溯源均可由 E2E 自动验收；
- [ ] Figure 导出资产校验和与原版相同。

### P4
- [ ] 10k+ 资产的虚拟列表/后台任务不卡 UI；
- [ ] 安装、卸载、升级及迁移在干净 Windows 11 通过；
- [ ] 零未解决 P0/P1 缺陷；
- [ ] 实际完成备份恢复演练并留证据。
